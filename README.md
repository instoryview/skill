# Instoryview Skill

An agent Skill that lets Claude Code, Codex, Cursor and other compatible assistants read your tracked Instagram accounts, retained follower / following snapshots and detected changes through [Instoryview](https://instoryview.com).

```bash
npx skills add instoryview/skill
```

It uses the connected Instoryview MCP tools, or the [`instoryview` CLI](https://github.com/instoryview/cli) if you have it installed and signed in. The Skill contains no credentials and installs nothing by itself. Never paste your API Key into a conversation.

Docs: https://instoryview.com/docs/skill
